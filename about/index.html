About this project

Helping older PCs stay useful

Old PC Guide is an independent informational project about getting practical use from older computers.

What you'll find here

The site brings together straightforward guides and an in-browser calculator for exploring older PC hardware.

Topics include lightweight Linux options, local AI tools and models, and ways to estimate whether a computer's processor and memory may be suitable for a task.

Calculator results are indicative estimates, not benchmarks or guarantees of compatibility. Actual results depend on the exact hardware, software versions, drivers, available memory and workload. Check the relevant requirements before installing software or buying components.
