Method and limitations

How the estimates work

This page explains what the calculator uses, what it leaves out, and how to check the official requirements before acting on an estimate.

What the calculator covers

The calculator uses a static, curated dataset in the site's db.js file, not a live hardware or model database.

  • 62 processor profiles across 11 groups, from representative 2003-era CPUs to 2024-era desktop, server, laptop and Apple Silicon examples. Some entries are generic profiles and explicitly require checking the exact model.
  • 47 graphics profiles, including representative NVIDIA, AMD and Intel products, plus manually entered VRAM where available.
  • 37 local model examples, including text, code, reasoning and vision-capable categories. These are examples, not a complete or ranked catalog.
  • 10 Linux distribution profiles. The calculator does not check whether an installer, driver or release is currently available for a particular machine.

Coverage is intentionally selective. A missing processor, graphics card or model does not mean it is unsupported; use the exact vendor or project documentation.

How the scores and memory estimates are made

The results are rules-based estimates produced by the site's own JavaScript formulas. They are not measured on a test bench.

  • The overall hardware index combines a table-based RAM score (45%) and an internal CPU index (55%). The PC year provides context; it is not itself a performance measurement.
  • Each CPU has an internal 0–100 index and recorded characteristics such as cores, clock, instruction-set class and memory generation. These values are heuristics, not results from a standardized benchmark.
  • Model memory estimates use example Q4_K_M file sizes and RAM budgets that assume a 2,048-token reference context. They do not represent the exact requirements of every download, runtime or model revision.
  • The model list has an internal CPU threshold used to filter results. Passing it only means the profile passes this site's indicative criteria; it is not a guarantee that a model will load or be useful.
  • Estimated tokens per second use internal CPU profile values, instruction class and memory-generation factors, or GPU profile values and whether the estimated model file fits known VRAM. The result is displayed as a range, not measured throughput. Manually entered GPU VRAM uses a wider uncertainty range.
  • Operating-system memory reserves and GPU offload are simplified. The estimates cannot see free RAM, shared memory use, swap activity, thermal throttling or background applications on your PC.

Real results vary with the exact device and CPU stepping, cooling and power limits, firmware, operating system, drivers, runtime and version, model file and quantization, context length, prompt, backend, GPU offload and other programs. Test the actual setup before relying on it.

Compatibility checks and source dates

External requirements change independently from this site. These official references were checked on October 15, 2026; recheck them before installing or buying hardware.

  • Microsoft's supported Intel processors for Windows 11 — used for the exact CPU names the calculator explicitly matches. A list match alone does not check TPM 2.0, Secure Boot, UEFI, storage or graphics requirements. Microsoft notes that processor lists may not reflect the newest offerings between updates.
  • Microsoft's supported AMD processors for Windows 11 — consult the current list for the exact CPU; the calculator does not infer support from generation or year.
  • LM Studio system requirements — the requirements differ by platform and build. For example, the current documentation lists AVX2 for Windows x64 and describes the Linux x64 package's AVX2 support.
  • Ollama FAQ and its GPU documentation — check the current context settings and GPU/backend compatibility.
  • Ollama model library and Hugging Face model pages — check the exact model repository, file, quantization, license and revision. The catalog does not pin or verify a specific downloadable file for every example.

Dataset limitation: the current static dataset does not record a source URL and verification timestamp for every individual CPU, GPU, model size or Linux release. The date above records this page's check of the linked references, not a claim that every dataset row was independently revalidated on that date. Where a per-entry source trail is needed, verify the exact specification with the manufacturer or project.

Tests and corrections

No repeatable hardware benchmark results are currently published by this page.

Calculator speed ranges are formula outputs, not results from running a named model on a named PC. We will only describe a result as a real test if the test was actually run and the hardware, operating system, runtime and version, model file and quantization, context settings and measurement method are reported.

For a correction or a reproducible test report, contact info@oldpcguide.com. Include the exact hardware and software versions and enough steps for another person to repeat it.
